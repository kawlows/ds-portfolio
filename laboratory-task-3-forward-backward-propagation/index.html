Laboratory Task 3

Instruction: Perform a forward and backward propagation in python using the inputs from Laboratory Task 2.

x = np.array([1, 0, 1])
y = np.array([1])

# use relu as the activation function.

# learning rate
lr = 0.001

This picks up right where Laboratory Task 2 left off. The forward pass is exactly the same computation as before, just written with matrices this time instead of doing each ZZZ and HHH by hand. The new part is the backward pass, where the error computed in Task 2 is used to figure out how much each weight should change.

Step 1: Set Up the Inputs and Weights¶

import numpy as np

Step 2: ReLU and Its Derivative¶

For the forward pass, only f(z)=max(0,z)f(z) = max(0, z)f(z)=max(0,z) is needed, same as in Laboratory Task 2. But for the backward pass, the derivative of ReLU is also needed, since backpropagation relies on the chain rule.

f′(z)={1z>00z≤0f'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \le 0 \end{cases}f′(z)={10​z>0z≤0​
(1)

Basically, if a unit was “on” during the forward pass (output greater than 0), the gradient flows through it. If it was “off” (clipped to 0), no gradient flows through it at all.

def relu(z):
    return np.maximum(0, z)

def relu_deriv(z):
    return (z > 0).astype(float)

Step 5: Backward Pass — Output Layer¶

The output error signal is the derivative of the loss with respect to ZoZ_oZo​. Since E=12(y−y^)2E = \frac{1}{2}(y-\hat{y})^2E=21​(y−y^​)2, its derivative with respect to y^\hat{y}y^​ is (y^−y)(\hat{y} - y)(y^​−y). Multiplying that by f′(Zo)f'(Z_o)f′(Zo​) (the ReLU derivative) gives the delta for the output unit:

δo=(y^−y)⋅f′(Zo)\delta_o = (\hat{y} - y) \cdot f'(Z_o)δo​=(y^​−y)⋅f′(Zo​)
(5)

Step 6: Backward Pass — Hidden Layer¶

The error now needs to be propagated one layer back. Each hidden unit’s delta depends on how much it contributed to the output error (through WoW_oWo​), scaled by its own ReLU derivative:

δh=(δoWoT)⋅f′(Zh)\delta_h = (\delta_o W_o^T) \cdot f'(Z_h)δh​=(δo​WoT​)⋅f′(Zh​)
(7)

∂E∂Wh=xTδh∂E∂θh=δh\frac{\partial E}{\partial W_h} = x^T \delta_h \qquad \frac{\partial E}{\partial \theta_h} = \delta_h∂Wh​∂E​=xTδh​∂θh​∂E​=δh​

A few things worth pointing out:

  • Any weight connected to the first hidden unit (w11w_{11}w11​, w13w_{13}w13​, w15w_{15}w15​, θ1\theta_1θ1​) didn’t change at all. That’s because Z1Z_1Z1​ was negative during the forward pass, so ReLU shut that unit off, and once a unit is off it stops passing gradient backward too.

  • The weights connected to the second hidden unit did move, since that unit was active.

  • With a learning rate this small (0.001), the updates are tiny after just one pass. It would take many iterations of this same process for the network to actually learn something useful, but this is exactly what happens on every single step of training.
