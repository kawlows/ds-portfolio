Laboratory Task 5

1. Perform Standard Imports


2. Create a function called set_seed() that accepts seed: int as a parameter, this function must return nothing but just set the seed to a certain value.


3. Create a NumPy array called “arr” that contains 6 random integers between 0 (inclusive) and 5 (exclusive), call the set_seed() function and use 42 as the seed parameter.


4. Create a tensor “x” from the array above


5. Change the dtype of x from int32 to int64


6. Reshape x into a 3x2 tensor
There are several ways to do this.


7. Return the right-hand column of tensor x


8. Without changing x, return a tensor of square values of x
There are several ways to do this.


9. Create a tensor y with the same number of elements as x, that can be matrix-multiplied with x
Use PyTorch directly (not NumPy) to create a tensor of random integers between 0 (inclusive) and 5 (exclusive). Use 42 as seed.
Think about what shape it should have to permit matrix multiplication.


10. Find the matrix product of x and y.

1. Standard Imports¶

import torch
import numpy as np

2. Seed-Setting Function¶

Random number generation in NumPy and in PyTorch are handled separately, each with its own generator and its own seed. Since this task uses random values from both libraries, set_seed() sets both np.random.seed() and torch.manual_seed() so that calling it once is enough to make every random value below reproducible, regardless of which library generated it. It has no return value, per the instructions — its only job is the side effect of fixing the seed.

def set_seed(seed: int):
    np.random.seed(seed)
    torch.manual_seed(seed)

3. Random NumPy Array¶

np.random.randint(low, high, size) draws from low (inclusive) up to high (exclusive), which matches the "0 (inclusive) and 5 (exclusive)" wording of the instructions. The dtype is set to int32 on purpose here — step 5 asks to change the tensor's dtype from int32 to int64 later, and that only makes sense to demonstrate if the array (and the tensor made from it) is actually int32 to begin with.

set_seed(42)
arr = np.random.randint(0, 5, 6, dtype=np.int32)
print(arr)
print(arr.dtype)
[3 4 2 4 4 1]
int32

4. Tensor from the NumPy Array¶

torch.from_numpy() wraps the existing array without copying it, and it carries the array's dtype over — so x starts out as an int32 tensor, matching arr.

x = torch.from_numpy(arr)
print(x)
print(x.dtype)
tensor([3, 4, 2, 4, 4, 1], dtype=torch.int32)
torch.int32

5. Changing the dtype¶

As the notebook's earlier section on dtypes points out, x = torch.tensor(x, dtype=torch.type) is the wrong way to do this — it triggers a tensor-cloning warning. The correct approach is the .type() method, which returns a new tensor cast to the requested dtype.

x = x.type(torch.int64)
print(x)
print(x.dtype)
tensor([3, 4, 2, 4, 4, 1])
torch.int64

6. Reshaping into 3×2¶

x has 6 elements, so it can be reshaped into any shape whose dimensions multiply to 6 — 3 rows by 2 columns in this case. Either .view() or .reshape() works here since x is contiguous in memory; .reshape() is used below since it also falls back gracefully to making a copy on tensors where .view() would raise an error.

x = x.reshape(3, 2)
print(x)
print(x.shape)
tensor([[3, 4],
        [2, 4],
        [4, 1]])
torch.Size([3, 2])

7. Right-Hand Column¶

Standard NumPy-style slicing carries over to tensors: x[:, 1] takes every row and column index 1, which is the second (right-hand) column.

right_col = x[:, 1]
print(right_col)
tensor([4, 4, 1])

8. Squared Values, Without Changing x¶

x.pow(2) (equivalently x ** 2 or torch.square(x)) returns a new tensor and leaves x untouched. The in-place version, x.pow_(2), would overwrite x, which is exactly what the instructions say not to do — printing x again afterward confirms it is still the original 3×2 tensor.

x_squared = x.pow(2)
print("Squared:")
print(x_squared)

print("\nx is unchanged:")
print(x)
Squared:
tensor([[ 9, 16],
        [ 4, 16],
        [16,  1]])

x is unchanged:
tensor([[3, 4],
        [2, 4],
        [4, 1]])

9. Building y for Matrix Multiplication¶

x is (3, 2). For x @ y to be valid, y's first dimension has to match x's second dimension, i.e. 2 rows. The instructions also ask for the same number of elements as x, which is 6, so y has to be (2, 3): 2 rows to satisfy matrix multiplication, times 3 columns to reach 6 elements. torch.randint(low, high, size) is the PyTorch equivalent of the NumPy call used for arr earlier, and the seed is reset to 42 right before it so this cell produces the same values on every run.

set_seed(42)
y = torch.randint(0, 5, (2, 3))
print(y)
print(y.shape)
tensor([[2, 2, 1],
        [4, 1, 0]])
torch.Size([2, 3])

10. Matrix Product of x and y¶

With x at (3, 2) and y at (2, 3), torch.mm(x, y) (equivalently x @ y or x.mm(y)) produces a (3, 3) result, following the same rule covered earlier in the notebook: an (a, b) tensor times a (b, c) tensor gives an (a, c) tensor.

product = torch.mm(x, y)
print(product)
print(product.shape)
tensor([[22, 10,  3],
        [20,  8,  2],
        [12,  9,  4]])
torch.Size([3, 3])
